# Python Uses

<div></div>

Python is a general purpose programming language and extremely flexible.

Some common uses include:

<v-clicks>

- **Web Development** - Flask and Django
- **Desktop GUIs** - Qt and GTK
- **Web Scraping** - Beautiful Soup
- **Mathematics & Data Science** - NumPy and SciPy
- **Scripting & Automation** - builds and testing
- **Machine Learning** - PyTorch, TensorFlow
- **Learning Programming** - readable syntax

</v-clicks>
