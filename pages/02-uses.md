# Python Uses

<div></div>

Python is a versatile, general-purpose programming language used for:

<v-clicks>

- **Web Development** - Django, Flask
- **Desktop Applications** - GTK, Qt
- **Web Scraping** - Beautiful Soup, Requests
- **Mathematics & Data Science** - NumPy, SciPy
- **Scripting & Automation** - builds and testing
- **Machine Learning** - PyTorch, TensorFlow
- **Education** - readable syntax
